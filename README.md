# Global Sales & Profit Analysis Dashboard

## 📊 Project Overview
This repository contains my first data analysis project using Microsoft Excel. The goal of this project is to analyze a comprehensive global sales dataset to uncover actionable business insights regarding revenue generation, cost management, and overall profitability across various regions and product categories.

By cleaning the raw data and utilizing advanced Excel features, I developed interactive dashboards that allow users to visually explore the financial performance of different sales channels and geographic markets.

## 🛠️ Tools & Techniques Used
- **Microsoft Excel:** Data Cleaning, Data Modeling, Pivot Tables, Pivot Charts, and Dashboard creation.
- **Data Processing:** Handling date formatting, standardizing monetary values, and creating calculated fields for comprehensive analysis.

## 📂 Dataset Details
- **File:**'project file.xlsx' 
- **Rows:** 1,000+ sales records
- **Key Variables Analysed:** 
  - `Region` & `Country`
  - `Item Type` (e.g., Household, Office Supplies, Cosmetics)
  - `Sales Channel` (Online vs. Offline)
  - `Units Sold`, `Total Revenue`, `Total Cost`, and `Total Profit`

## 📈 Key Insights Discovered
After analyzing **$231.2 Million** in total global revenue, here are the primary findings:
1. **Top Performing Region:** Europe is the most profitable market globally, generating **$15.45 Million** in total profit.
2. **Most Profitable Product:** **Household** items drive the highest profit margins compared to all other item types in the dataset.
3. **Sales Channel Dominance:** **Online** sales significantly outperformed Offline sales, bringing in **$42.3 Million** in profit versus the $30.5 Million generated by offline channels.
